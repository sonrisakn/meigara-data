# 配当の木の数字の置き場

上場している会社の決算の数字を、アプリが読むために置いています。

- 出典：EDINET閲覧（提出）サイト（https://disclosure2.edinet-fsa.go.jp/）、公共データ利用規約（第1.0版）
- ここの数字は、EDINET の書類をもとに「配当の木」が作成したものです（計算した数字をふくみます）。国が作ったそのままの数字ではありません。
- 作った日：2026-10-28 18:07

## ファイル
- `版.json`：作った日と会社の数
- `一覧.json`：全社の一覧（会社名・業種・決算の日の値段・20個の数字）
- `会社/コード.json`：会社ごとの毎年の数字（損益・財務・CF・配当）
- `app/`：ウェブ版のアプリ（ためし版）
